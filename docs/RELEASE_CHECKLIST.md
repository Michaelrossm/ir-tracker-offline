# Release-Prüfliste / Release checklist

## Deutsch

- [ ] Version, Änderungsprotokoll und Dateinamen stimmen überein.
- [ ] Automatische Tests und PlatformIO-Build sind erfolgreich.
- [ ] Firmwarepaket ist signiert und unabhängig verifiziert.
- [ ] Keine Originalsicherung, privaten Schlüssel, Passwörter oder Zähler-PINs im Paket.
- [ ] Deutsch/Englisch-Umschaltung auf allen Webseiten geprüft.
- [ ] Desktop und Smartphone geprüft.
- [ ] Backup/Wiederherstellung und signiertes OTA auf Hardware geprüft.
- [ ] 72-Stunden-Dauertest dokumentiert.
- [ ] SHA-256-Prüfsummen veröffentlicht.

## English

- [ ] Version, changelog and filenames match.
- [ ] Automated tests and PlatformIO build pass.
- [ ] Firmware package is signed and independently verified.
- [ ] No original image, private key, password or meter PIN in the package.
- [ ] German/English switching verified on every web page.
- [ ] Desktop and smartphone verified.
- [ ] Backup/restore and signed OTA verified on hardware.
- [ ] 72-hour soak test documented.
- [ ] SHA-256 checksums published.
